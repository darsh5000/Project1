## Claude Code on GitHub

This repo has a `.github/workflows/claude.yml` workflow that lets you trigger Claude Code
directly from GitHub. Mention `@claude` in an issue, a PR comment, or a PR review, and a
Claude Code session will investigate and respond or push a fix.

Requires an `ANTHROPIC_API_KEY` secret to be set in the repo's GitHub Actions settings
(Settings → Secrets and variables → Actions).
